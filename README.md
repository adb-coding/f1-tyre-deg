# F1 Tyre Degradation API

FastAPI backend computing F1 tyre-degradation, telemetry and session data with
[fastf1](https://github.com/theOehrly/Fast-F1). Frontend hosted separately on Netlify.

Endpoints live under `/api/...` (e.g. `/api/tyre-degradation`, `/api/driver-data`,
`/api/session-info`).
